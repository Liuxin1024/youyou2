# 作品集各屏职责说明

> 单页作品集（非多路由）。纵向滚动结构。  
> 更新日期：2026-07-26  
> 定位：平面设计师个人站（you you）

## 整站逻辑

```
Loading 定调
  → Hero 立人设
  → 核心项目 秀成果
  → 能力范围 讲能做什么
  → 更多作品 展广度
  → 数据背书 建信任
  → 联系合作 要转化
```

## 2. Selected Works（核心项目 / `#work`）

| 项 | 说明 |
|----|------|
| **组件** | `SelectedWorks.tsx` |
| **职责** | 展示最硬的代表作，让访客快速判断能力与风格 |
| **内容** | 眉题 Selected Work；标题「核心项目」；副文案；4 张 Bento 项目卡片（悬停 View） |
| **分工** | 完整项目（有行业、有结果感） |

---

## 3. Capabilities（能力范围 / `#capabilities`）

| 项 | 说明 |
|----|------|
| **组件** | `Capabilities.tsx`（由原 Journal 改造，方案 A） |
| **职责** | 能力 / 服务切片：快速说明「我能做什么」 |
| **内容** | 眉题「能力范围」；标题「我能做什么」；副文；四条：插画创作、品牌视觉、电商详情页、新媒体内容 |
| **风格** | 扫能力 + 看图，不是文章列表 |

## 4. Explorations（更多作品 / `#explorations`）

| 项 | 说明 |
|----|------|
| **组件** | `Explorations.tsx` |
